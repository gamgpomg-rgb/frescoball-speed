# frescoball-speed

フレスコボールの7mラリーを、打音または240fps動画から計測するローカルPWAとPython解析ツールです。動画・音声・記録は端末内で処理し、標準では外部へ送信しません。

## 最短の使い方（HTTPS）

初回だけ、Macにローカル開発用の認証局を用意します。これはこのアプリ専用の設定変更ではなく、`mkcert` の標準的なローカルHTTPS設定です。

```bash
brew install mkcert
mkcert -install
```

以後の起動は1コマンドです。

```bash
./scripts/serve.sh
```

表示された `https://127.0.0.1:8443/` をMacのブラウザで開きます。HTTPへのフォールバックはしないため、カメラ・マイクの安全な利用条件を崩しません。

### iPhone / iPadで使う

1. Macと端末を同じ信頼できるWi-Fiへ接続します。
2. Macで `./scripts/serve.sh --lan` を実行し、表示された `https://<MacのLAN IP>:8443/` を端末で開きます。
3. 初回のみ、`mkcert -CAROOT` にある **`rootCA.pem` だけ** を端末へ安全に転送してプロファイルをインストールし、「設定 > 一般 > 情報 > 証明書信頼設定」で信頼を有効にします。秘密鍵は絶対に転送しません。
4. Safariの共有メニューから「ホーム画面に追加」を選ぶとPWAとして起動できます。

不特定多数がいるネットワーク、他人の認証局、公開インターネットへの公開では使わないでください。`--lan` は終了時にCtrl-Cで停止します。

## 計測の仕様

`measurement-spec.json` がWebとPythonの唯一の計算正本です。

- 初速換算は、ボール寸法・質量・抗力からの理論モデルを空欄時の既定にします（7mで平均速の約`1.07008`倍）。実測校正値はスピードガン等の根拠がある場合だけ、設定の「実測校正係数」に入力します。
- 片側マイクでは、最初の打音がマイクの近側か遠側かを明示します。近側→遠側の観測間隔からは音の伝搬時間を引き、遠側→近側では足します。
- ライブ・動画解析とも、補正後の飛行時間が0.20〜0.90秒、かつ初速が設定上限（既定110km/h）以内のものだけ速度集計に採用します。除外された打音は打数には残り、画面に理由が出ます。
- マイク開始後0.75秒と動画先頭0.50秒は、入力・フィルタの初期ノイズを学習する安定化期間です。この間の音は打数にも速度にも入りません。安定化後の実測90km/h超は、設定上限以内なら通常どおり集計します。

計算仕様を更新したら次を実行します。

```bash
python3 scripts/sync_measurement_spec.py
./tests/run_tests.sh
```

## PWAの機能

- ライブ打音計測: マイク入力は解析専用の無音経路に接続され、スピーカーには出ません。効果音・BGMのみ通常どおり再生されます。新しく開いた画面は必ず0から始まり、保存済みの集計は「前回の集計を再開」を押したときだけ復元します。
- 動画解析: 新しい動画を選んだ時点で前の速度・打数表示を0へ戻し、古い解析処理が後から新しい結果を上書きしないようにします。音声検出後に「映像で精査」をすると、打者の左右判定・隣の組の除外を反映して同じ記録を更新します。
- 保存: 設定とライブ集計はブラウザのローカルストレージ、動画解析記録はIndexedDBに保存します。記録には選手、設定、計算仕様、映像精査バージョンを保持します。旧記録は開いたときに互換形式へ移行します。
- 出力: 動画解析ダッシュボードからJSON（完全な記録）とCSV（打音ごとの時刻・選手・初速）を端末へ出力できます。

通常のライブ計測は外部通信なしで動きます。大容量MP4の音声トラック解析では初回に`mp4box.js`、外部AI雑音除外をオンにした場合は初回にモデルを取得します。PWAの基本画面と計算仕様はサービスワーカーでキャッシュします。

## Pythonの事後解析

Pythonツールは任意です。専用仮想環境を作ります。

```bash
./scripts/setup_venv.sh
```

```bash
.venv/bin/python scripts/video_speed.py rally.mov --fps 240
.venv/bin/python scripts/audio_speed.py rally.mov --mic-pos center
.venv/bin/python scripts/audio_speed.py rally.mov --mic-pos near --first-onset-side near
```

動画から音声を抽出する場合は `ffmpeg` も必要です（`brew install ffmpeg`）。環境確認は次で行えます。

```bash
.venv/bin/python scripts/diagnose.py --strict
```

## 検証

```bash
./tests/run_tests.sh
```

このテストは、WebとPythonの理論係数、片側マイクの補正符号、品質ゲート、および生成済みWeb仕様の一致を確認します。
